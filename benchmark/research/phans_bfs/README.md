# PHANS with BFS-Based Null-Agent Selection

## Idea

This PHANS variant uses BFS distances on the grid to help choose which null agent to move when clearing a blocking agent. The distance calculation respects static obstacles.

## Benchmark entry point

The benchmark can load this solver as:

`benchmark.research.phans_bfs.solver:solve`
